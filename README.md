# 클라우드 비서 (메일 전용)

맥이 꺼져 있어도 도는 부분. GitHub Actions 가 10분마다 실행한다.

## 역할 분담

| | 감시 대상 | 언제 도나 |
|---|---|---|
| **클라우드 비서** (여기) | 네이버 메일 | 24시간 |
| **맥 비서** (`../secretary/`) | 구글 드라이브, 카톡 | 맥이 켜져 있을 때 |

둘 다 같은 텔레그램 봇(`선우야 비서해`)으로 알림을 보낸다.
업무 ID 앞에 `naver-` / `drive-` 가 붙어 서로 겹치지 않는다.

## 필요한 GitHub Secrets

| 이름 | 값 |
|---|---|
| `NAVER_ID` | `fabulousunw` |
| `NAVER_PW` | 네이버 **애플리케이션 비밀번호** (12자) |
| `TG_TOKEN` | 텔레그램 봇 토큰 |
| `TG_CHAT` | 텔레그램 chat_id |

## 공개 저장소로 두는 이유

비공개 저장소는 Actions 무료 한도가 월 2,000분이라 10분 간격(월 4,320회)을 못 버틴다.
공개 저장소는 무제한이다.

**그래서 `state.json` 에는 메일 내용을 저장하지 않는다** — UID 와 시각만 남기고,
재알림에 필요한 제목은 그때 IMAP 에서 다시 가져온다. 비밀번호는 Secrets 에만 있고
저장소에는 없다.

## 알아둘 한계

GitHub 의 예약 실행은 **정시를 보장하지 않는다.** 부하가 걸리면 10~25분씩 밀린다.
"10분 안에 확인" 판정이 그만큼 느슨해진다. 정확한 타이밍이 꼭 필요하면
싼 VPS 로 옮기는 편이 낫다.

또 저장소에 60일간 아무 활동이 없으면 예약 실행이 자동으로 꺼진다.
